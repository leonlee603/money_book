## Introduction

This is a small project to practice performing CRUD by server actions.

## Stacks

- Framework: Next.js
- Authentication: Clerk
- Database: Neon & Drizzle ORM
- Layout: Shadcn & Tailwind CSS
- Validation: Zod

## Project is hosted on Vercel

You can check the demo [here](https://money-book-delta.vercel.app/)
